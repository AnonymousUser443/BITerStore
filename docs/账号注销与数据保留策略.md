# 梨苑儿账号注销与数据保留策略

更新时间：2026-09-15

## 注销后立即发生的变化

- 撤销全部登录会话，清除 H5 Cookie，并解除微信快捷登录绑定。
- 下架并软删除该账号尚未删除的商品；旧商品不会在账号恢复后自动上架。
- 清除学号明文、昵称、头像、校区、简介、收藏、拉黑关系和站内通知。
- 撤销校园身份状态，并移除管理员角色、TOTP 密钥及其他管理权限。

## 30 天恢复期

注销后 30 天内，系统仅保留使用独立服务端密钥计算的校园身份 HMAC 关联，用于确认是原账号本人；它不保存学号明文，也不能在没有密钥的离线数据库中直接枚举还原。用户重新完成校园认证后，可恢复原账号；公开资料仍采用默认值，旧商品保持下架。

`ACCOUNT_RECOVERY_DAYS` 用于配置恢复期。`CAMPUS_IDENTITY_HASH_KEY` 必须是独立长随机密钥，不能与登录签名或 TOTP 加密密钥复用。运维任务 `npm run accounts:cleanup-recovery` 应至少每天运行一次；它会删除超过恢复期的校园身份关联。关联删除后，再次认证会创建新账号，原账号不可恢复。

该 HMAC 密钥也是恢复关联的一部分，不能直接轮换或丢失；如需轮换，应先实现双密钥读取与在线重算迁移，并单独验收恢复流程。

## 必要记录

为保障另一方查看既有会话、处理交易纠纷、安全事件和举报，消息、举报、审核及审计记录不会在注销请求中直接物理删除，但账号的公开身份已替换为“已注销用户”，且不再保留学号明文。需要进一步处理特定记录时，应通过项目公布的隐私联系渠道核验申请，并结合纠纷、安全与法定义务处理。

上线前应由项目负责人补齐正式用户协议中的隐私联系方式、法定保存期限和人工请求流程；本文描述的是当前代码实际执行的技术边界。
